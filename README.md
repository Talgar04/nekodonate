# Neko Donate

Донаты с Kaspi Gold прямо на стрим — алерты и озвучка (қаз/рус) в OBS. Зритель просто переводит на Kaspi стримера; уведомление о зачислении ловится (Android-приложение или iPhone через «Связь с телефоном»), и через секунду на стриме «Имя Ф. — сумма — сообщение».

## Программа для стримеров (Windows)

Каждый стример ставит **Neko Donate для Windows** на свой стрим-компьютер — сервер, панель, оверлеи OBS и приём с iPhone внутри. Работает, пока работает стрим; общий сервер не нужен.

- Сборка установщика: `cd apps/desktop && npm run dist` → `apps/desktop/release/NekoDonate-Setup-<версия>.exe` (~100 МБ, без подписи — Windows покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае»).
- Панель: http://localhost:4747/app · OBS: `http://localhost:4747/overlay/...` · данные: `%APPDATA%\Neko Donate\data` (ключ `secret.key` не терять).
- Автозапуск с Windows (в трей), значок у часов: панель, виджеты, телефон, автозапуск вкл/выкл, выход.
- Автообновление (с 0.2.2) — через GitHub Releases `Talgar04/nekodonate`. Новая версия: поднять `version` в `apps/desktop/package.json` → `npm run dist` → на GitHub создать релиз с тегом `v<версия>` и загрузить из `release/` три файла: `NekoDonate-Setup-<версия>.exe`, `.exe.blockmap`, `latest.yml`. Программы стримеров подтянут его сами (проверка при запуске и раз в 6 часов).

## Сайт (Netlify)

Исходники — `site-src/` (страницы в `pages/`, общие стили и скрипт в `static/`), готовая папка — `site/`.

1. `node site-src/build.mjs` — собирает `site/`, кладёт в `site/download/` установщик Windows и APK, рисует QR.
   Перед сборкой: `$env:NEKO_CONTACT="@galymov04"` (контакт в политике) и `$env:NEKO_INSTALLER_URL="https://github.com/Talgar04/nekodonate/releases/download/v<версия>/NekoDonate-Setup-<версия>.exe"`.
   Netlify Drop не принимает установщик (~95 МБ), поэтому он лежит на GitHub Releases, а в `site/` не копируется.
2. app.netlify.com → сайт `nekodonate` → Deploys → перетащить папку `site` (или её zip). Адрес: https://nekodonate.netlify.app

## Разработка (Node.js 22.13+)

**Проще всего:** двойной клик по `Запуск.cmd` — соберёт всё при первом запуске, поднимет сервер и откроет панель. Окно не закрывать во время стрима.

Или вручную:

```powershell
cd KaspiGoldAlerts
npm install
npm run build        # собрать сайт (apps/web → dist)
npm start            # сервер на http://localhost:3000
```

1. Откройте http://localhost:3000/app и зарегистрируйтесь. **Первый аккаунт становится админом с тарифом VIP навсегда.**
2. «Настройки» → укажите номер Kaspi и имя получателя.
3. «Виджеты OBS» → скопируйте ссылку «Алерты» → OBS: Источник «Браузер», 1920×1080, включите «Управлять звуком через OBS».
4. «Эфир» → «Тест-алерт», чтобы проверить оверлей и озвучку.
5. «Эфир» → «Тест уведомления»: проверка разбора и сопоставления без телефона.
6. Страница доната: `http://localhost:3000/@ваш_ник`.

**Чтобы видели телефон и зрители**, адрес `localhost` не подходит:
- телефон в той же Wi-Fi сети: в `apps/server/.env` укажите `PUBLIC_URL=http://IP-компьютера:3000` (см. `.env.example`);
- зрители из интернета: нужен публичный адрес — туннель (Cloudflare Tunnel / ngrok) или VPS. Тогда в `PUBLIC_URL` указывается этот адрес.

Режим разработки с горячей перезагрузкой: `npm run dev` (сайт — http://localhost:5173, API проксируется на 3000).

## Структура

| Путь | Что это |
|---|---|
| [apps/server](apps/server) | Node.js + Fastify + встроенная SQLite (`node:sqlite`). API, WebSocket, очередь алертов, сопоставление, озвучка, админка |
| [apps/server/src/db.ts](apps/server/src/db.ts) | Схема БД и миграции (новые изменения — только добавлением в конец списка) |
| [apps/web](apps/web) | Vite + React: лендинг, донорская страница, панель стримера, админка; оверлеи OBS (без фреймворка, пружины Motion) |
| [apps/android](apps/android) | Android-приложение (Kotlin/Compose): ловит уведомления Kaspi, шлёт на сервер с HMAC-подписью. Сборка — в Android Studio, см. его README |
| [packages/shared](packages/shared) | Общие типы протокола WebSocket |
| [docs](docs) | Архитектура, протокол WS, протокол телефонов, план |

Данные лежат в `apps/server/data/` (база, загруженные файлы, кэш озвучки, ключ шифрования `secret.key` — **его не терять**: без него не расшифровать реквизиты).

## Что умеет

- **Донор:** форма (сумма-пресеты, имя, сообщение со счётчиком озвучки, ссылка YouTube для VIP), уникальная сумма для автоузнавания, копирование суммы и номера в одно касание, живой статус «перевод получен → показано на стриме», қаз/рус.
- **Узнавание перевода — на выбор:** уникальная сумма / ровная сумма + имя / только вручную; «доверять кнопке донора»; переводы без заявки — алертом или на проверку; спорные случаи — в «Требует внимания» с кандидатами.
- **Источники переводов:** Android-приложение; Быстрая команда iOS по SMS; ручное подтверждение; ручной донат (наличные).
- **Оверлеи:** алерты (вход/выход по одной траектории, звук, озвучка, варианты по сумме, свой CSS), медиа YouTube, цель сбора. Очередь на сервере — перезагрузка OBS ничего не теряет. Задержка перевод → экран ≈ 70 мс (озвучка догоняет).
- **Озвучка:** Microsoft Edge (бесплатно, есть казахские голоса Айгүл/Дәулет) или Yandex SpeechKit (по ключу); язык определяется сам.
- **Модерация:** фильтр мата қаз/рус с заменами букв, свои слова (звёздочки / скрыть / на проверку), вырезание ссылок и номеров, пре-модерация с задержкой, бан доноров.
- **Тарифы Free / Pro / VIP** с лимитами; админ выдаёт/продлевает/сбрасывает вручную (с причиной в журнал).
- **Панель:** эфир-пульт (пауза, пропуск, повтор, выкл. озвучки, тест), история с фильтрами, сводки, CSV, устройства, PWA для телефона.
- **Админка:** пользователи, тарифы, счётчики, блокировки, роли; редактор правил разбора уведомлений Kaspi с тестом на образцах и откатом версий; MRR, доля неразобранных, задержка; журнал действий; CSV.
